# Happy hour finder

A one-page website that shows bars with a happy hour on in Sydney and Melbourne, closest to you first.

- `index.html` is the whole app (plain HTML and JavaScript, no build step).
- `venues.js` is the list of bars, deals and times (Sydney and Melbourne). Edit it in GitHub to add or fix a venue; the instructions are at the top of the file.

Deal details come from public happy hour guides (each venue links to its source) and change often.
